🎯 MONITORING COMMANDS (Run any of these)

1️⃣  VIEW LIVE DASHBOARD (Recommended)
   python3 dashboard-monitor.py
   
   Shows real-time organization activity with:
   • Request counts per org
   • What data they're accessing (Controls, Evidence, etc)
   • Last access time
   • Source IP addresses

2️⃣  WATCH RAW ACCESS LOG
   tail -f access.log
   
   Shows every request in format:
   [timestamp] | METHOD | /endpoint | Status | Auth | IP

3️⃣  ANALYZE HISTORICAL ACTIVITY
   python3 analyze-access.py
   
   Shows summary statistics:
   • Total requests by organization
   • Access patterns by data type
   • Timeline of activity

4️⃣  VIEW NGROK INSPECTOR
   Open: http://localhost:4040
   
   Web UI showing:
   • All tunnel requests
   • Request/response details
   • Network timing
   • Full request/response bodies

📊 WHAT THE LOGS SHOW

Access Log Entry Example:
  2026-09-09T13:20:57 | GET    | /notifications | Status: 200 | Auth: org:80052... | IP: 2401:49...

Breaking it down:
  • Timestamp        = When the request happened
  • METHOD           = HTTP verb (GET, POST, PATCH)
  • Path             = What endpoint was called
  • Status           = HTTP response code (200 OK, 404 Not Found, etc)
  • Auth             = Who made the request (org ID)
  • IP               = Where the request came from
